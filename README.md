# ทันอากาศ — เขตสุขภาพที่ 7

ระบบต้นแบบดึงข้อมูลสาธารณะ สร้างแผนที่และรายงาน A4 แล้วส่ง LINE ส่วนตัว เปลี่ยนตัวเลข สี และคำแนะนำด้วยโค้ด ไม่มีการสร้างตัวเลขด้วย AI

## สถานะ

ทดสอบดึงข้อมูลและคำนวณในเครื่องแล้ว ยังไม่ได้ติดตั้งบนบัญชีออนไลน์ และยังไม่เปิดส่งประจำวัน

## เริ่มใช้งานออนไลน์ (ต้องตั้งค่าบัญชีครั้งแรก)

1. สร้างบัญชี GitHub และ repository ใหม่สำหรับระบบนี้ หากใช้บริการฟรีให้เลือก public โดยเผยแพร่เฉพาะชุดติดตั้งที่เตรียมให้ ไม่อัปโหลดทั้งโฟลเดอร์งาน
2. อัปโหลดไฟล์จาก `release/than-akat-online` (ไม่รวม `.env` หรือ private-cache)
3. Settings → Secrets and variables → Actions → New repository secret: ใส่ `LINE_CHANNEL_ACCESS_TOKEN` และ `LINE_USER_ID` จากไฟล์ `.env` ในเครื่อง ห้ามใส่ในโค้ดหรือแชต
4. Settings → Pages → Source เลือก GitHub Actions
5. Actions → Than Akat daily report → Run workflow โดยยังไม่เลือก send_line เพื่อตรวจภาพและข้อมูลก่อน
6. เมื่อตรวจผ่าน รันอีกครั้งโดยเลือก send_line เพื่อทดสอบภาพเข้า LINE
7. งานประจำตั้งเริ่ม 07.00 น. Asia/Bangkok การเข้าคิวและต้นทางอาจทำให้ส่งหลังเวลานี้ GitHub ไม่รับประกันตรงนาที

GitHub Pages เปิดเผยภาพรายงาน สถิติสรุปและวิธีคำนวณเท่านั้น ข้อมูลดิบห้องปลอดฝุ่นที่มีชื่อ/โทรศัพท์/อีเมลอยู่ใน private-cache และไม่ถูกเผยแพร่

## การคำนวณและข้อจำกัดที่ต้องรับทราบ

- รายจังหวัดเฉลี่ยสถานีที่รายงานครบ ณ เวลาเดียวกัน ค่าเฉลี่ยเขตเฉลี่ยสี่จังหวัดให้น้ำหนักเท่ากัน ไม่ใช่ค่าเฉลี่ยเชิงพื้นที่หรือประชากร
- ข้อมูลหลักใช้ค่าเฉลี่ย 24 ชั่วโมงล่าสุดจาก Air4Thai พร้อมเวลา ไม่ใช้ค่ารายชั่วโมงแทน
- ตารางย้อนหลังใช้ข้อมูลรายชั่วโมงครบ 24 จุด `(เวลา07:00ก่อนหน้า, เวลา07:00วันนี้]` ถ้าขาดจุดหนึ่งจะแสดง —
- ตรวจเทียบค่าเฉลี่ยที่คำนวณกับค่าต้นทางได้ตรงกันถึงทศนิยมหนึ่งตำแหน่งในสี่สถานี ณ 29 ต.ค. 2569 11:00
- ระบบเก็บข้อมูลคัดกรอง PHEOC แยกจากค่าฝุ่นเฉลี่ย โดยใช้ค่าสูงสุดของสถานีในจังหวัด ค่าคัดกรองไม่ยืนยันการเปิด/ปิดศูนย์จริง
- เงื่อนไขหนึ่งปีห้องปลอดฝุ่นใช้วันประเมินตนเองตามขอบเขตผู้ใช้ รวมวันครบรอบย้อนหลัง ไม่ใช่อ้างอายุรับรองโดยเจ้าหน้าที่
- API ห้องปลอดฝุ่นไม่มีรหัสห้องถาวร จึงนับรายการต้นทาง ไม่รวมรายการชื่อสถานที่เดียวกันอัตโนมัติ เพราะอาจเป็นคนละห้อง หากมีแถวซ้ำทุกช่อง ระบบหยุดเพื่อให้ตรวจ
- ประเภทข้อมูลต้นทาง “สถานบริการสาธารณสุข” ไม่ใช่ “โรงพยาบาล” ทั้งหมด และ “สถานพัฒนาเด็กปฐมวัย” กว้างกว่าศูนย์พัฒนาเด็กเล็ก จึงใช้ชื่อประเภทจริง
- รายงานจะแจ้งข้อมูลไม่ครบอย่างชัดเจน ไม่แทนข้อมูลขาดด้วยศูนย์
- LINE ใช้ retry key คงที่ต่อวันเพื่อป้องกันส่งซ้ำภายในช่วงเวลาที่ LINE รองรับ (24 ชั่วโมง); ไม่รับประกันข้ามช่วง 24 ชั่วโมง
- ภาพพื้นหลังสร้างด้วย AI ตามแบบที่ผู้ใช้เลือก ตัวอักษร ตาราง แผนที่และตัวเลขจริงสร้างด้วยโค้ด

## คำสั่งพัฒนา

PowerShell: `./system/fetch.ps1 -Date 2026-10-29`

`node --test system/test.mjs`

`node system/build.mjs --date 2026-10-29`

`node system/send.mjs` รับกุญแจจาก environment เท่านั้น ไม่มีการส่งโดยอัตโนมัติขณะ build/render
